## 3. Signed inbound webhook over real loopback HTTP

The server was started separately with the same database and secrets:

```bash

curl --fail http://127.0.0.1:18080/v1/ready
```

The request body contained a mock task with idempotency key `grok-e2e-webhook-mock`. The signature was computed from the exact raw body and sent without logging it:

```bash

SIGNATURE="$(uv run --no-sync python -c '<HMAC-SHA256 of timestamp.raw-body using MAX_AGENT_WEBHOOK_SECRET>' "$TIMESTAMP")"
curl --fail -X POST http://127.0.0.1:18080/v1/inbound/webhook \
  -H 'Content-Type: application/json' \
  -H "X-Max-Timestamp: $TIMESTAMP" \
  -H "X-Max-Signature: $SIGNATURE" \
  -H 'X-Max-Delivery-Id: grok-e2e-delivery-1' \
```

## Residual risk and follow-up

- **External CLI not accepted:** install and authenticate a real vendor CLI only with operator authorization, then require `real_cli_invoked: true`, a successful version probe, terminal success, verification, and artifacts. Do not count `auto` + stub as that acceptance.
- **Quota and cost:** no paid API was called. Vendor authentication, quota exhaustion, rate limits, latency, and actual usage cost remain untested.
- **Timeout and cancellation:** no real vendor timeout/cancellation was exercised. The kernel timeout cannot kill an in-process worker thread; the bounded subprocess boundary has separate process-group controls.
- **Crash recovery:** no external CLI crash/restart drill occurred. Lease recovery and idempotency must be tested with the real vendor before allowing side effects.
- **Isolation:** an isolated worktree and sandbox flags are not a VM or user boundary. Do not provide production credentials or production write targets.
- **Fallback visibility:** `auto` can succeed through the stub even when the external gate is enabled; always inspect `vendor`, `real_cli_invoked`, probes, and the event journal.
- **HTTP ownership:** webhook-created tasks currently belong to `user`; a different `MAX_AGENT_API_ACTOR` cannot read them. Keep this aligned or use CLI status/events as demonstrated.
