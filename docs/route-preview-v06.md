# Route preview (Issue #78, initial slice)

`POST /v1/routes/preview` accepts `{"task_id":"..."}` with the existing bearer token. The task must opt in through `worker_payload.route`, for example `{"unit":"USD","upper_bound":"4","capabilities":["code"],"effort":"high","vendor_pin":"codex"}`. The upper bound is a caller-approved maximum in its original unit, never derived from tokens or mixed with other currencies.

The read-only evaluator orders the owner's accounts by provider/account key and models by model key. It reports stable reason codes for disabled accounts/models, capability and effort mismatch, vendor pin mismatch, closed worker/model binding gates, missing or manually entered price, unit mismatch, insufficient Global/Provider/Task budget, and wrong billing mode or credential reference. Preview cannot grant CLI authorization and does not create an attempt, lease, reservation or event. A price source must be an HTTPS source to count as trusted for a paid candidate; configured `manual:` and `fixture:` prices remain visible but rejected.

The CLI adapter now has a validated `bound_model` argv contract for Codex and Claude. Grok has no model binding path. Routed accounts must be `api_metered` and use `env:OPENAI_API_KEY` for Codex or `env:ANTHROPIC_API_KEY` for Claude. The claim rechecks that binding. The child receives only the selected key in an isolated HOME; it cannot inherit alternate provider credentials, base URLs, auth tokens or model environment overrides. A missing key fails before workspace creation. This is an offline contract, not evidence that a particular installed CLI accepts the option or honors it for a paid run. Consequently the production preview and claim leave the worker and binding gates closed. Claiming an opted-in task records `route_rejected` before any attempt or paid dispatch; legacy tasks are unaffected. Internal tests can inject synthetic gates to exercise the future claim path: it rechecks account/model/price, then writes a `route.v1` decision and all three budget holds in the same transaction as the attempt and fence. Route decisions are immutable at the database layer; trace shows the chosen account/model/price and reservation state without credentials. Finalization settles only a measured, unit-matching cost with verified real invocation, model and provider; otherwise the hold remains pending reconciliation. Expired leases retain the hold.

This remains Draft. The production gates must only open after version-specific CLI preflight and an authorized live drill. Issue #82 introduces an independent `spend_ceiling_unenforced` reason. A caller-supplied amount is a reservation quote, not a guarantee that the CLI cannot exceed it; see [spend-ceiling-v06.md](spend-ceiling-v06.md) for the narrower single-request API bound. Preview availability is only a snapshot and never authorizes execution.
